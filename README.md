ChapaChat – Privacy-Aware Messaging SystemChapaChat is a secure, privacy-focused web messaging system developed for ChapaChat Kenya using plain PHP 8, MySQL (PDO), HTML5, CSS3, JavaScript, and Bootstrap 5.The application addresses two critical security vulnerabilities present in standard messaging systems:1\.	Private conversations leaked through shared system logs — Resolved by implementing strict privacy-aware audit logging where message body text is never stored in audit logs.2\.	Deleted messages remaining visible or recoverable in system storage — Resolved by implementing cryptographic zeroization soft-deletion, where the encrypted\_text field is overwritten with an empty string in MySQL upon deletion.\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_1\. Installation Guide (XAMPP Local Deployment)Follow these steps to deploy ChapaChat locally on XAMPP:1\.	Copy Application Files: Copy the entire chapachat project folder into your XAMPP htdocs directory:C:\\xampp\\htdocs\\chapachat2\.	Start XAMPP Services: Open the XAMPP Control Panel and start both Apache and MySQL.3\.	Import Database Schema:\-	Open phpMyAdmin in your browser: http://localhost/phpmyadmin\-	Create a new database named chapachat with collation utf8mb4\_unicode\_ci.\-	Select the chapachat database, click on the Import tab, choose database/chapachat.sql, and click Go.4\.	Configure Application:\-	Navigate to the config/ directory inside chapachat.\-	Copy config.sample.php to config.php:copy config\\config.sample.php config\\config.php\-	Open config/config.php in a text editor and ensure APP\_KEY contains a valid 64-character hex key (a default secure key is pre-configured).5\.	Launch Application: Open your browser and visit:http://localhost/chapachat\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_\_3\. Security \& Privacy Features\-	Role-Based Access Control (RBAC): Strict permission enforcement via require\_role('Administrator') with HTTP 403 access logging.\-	Multi-Factor Authentication (OTP): Random 6-digit OTP code, hashed in otp\_code table, with 5-minute expiry. Demo alert box for local XAMPP environments. Account lockout after 3 consecutive failed login attempts.\-	AES-256-CBC Encryption: Unique 16-byte random IV generated per message payload. Only base64 ciphertext is stored in MySQL.\-	Cryptographic Zeroization Deletion: Deleting a message overwrites encrypted\_text with '', ensuring content is unrecoverable.\-	Privacy-Aware Audit Logging: Audit log stores action type, timestamp, user ID, and IP address. Plaintext passwords, OTPs, and message bodies are strictly prohibited from appearing in audit logs.\-	Database Backup \& Recovery: Pure PHP database export to .sql snapshot files protected by .htaccess. Restoring preserves zeroized deleted messages.
